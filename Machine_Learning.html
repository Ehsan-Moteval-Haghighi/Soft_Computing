Machine Learning

Learning from physical and spatial data, and proving the model works where it was not trained.

Data preparation

Most of a model’s quality is decided before training. I make the data trustworthy and meaningful first.

Mechanics

Designing training data

Generating simulation datasets that cover the right loading paths, so a network can learn material behaviour.

Geoscience

Cleaning real-world data

Harmonising drill-hole logs and assays from many sources, and catching unit, position and value errors.

Statistics

Censored measurements

Keeping below-detection-limit results as what they are, instead of replacing them with guesses.

Feature engineering

Physics-aware features

Turning domain knowledge into inputs: for example, the distance and direction to the nearest logged rock type or mineral.

Data fusion

Combining sources

Joining drill-hole context with satellite, topographic and geophysical rasters for the same location.

Practice

Traceability

Provenance, interval identifiers and QA outputs, so every later result can be traced back to its data.

Model evaluation

A model is only as good as the test it passes. I test the way a sceptical reviewer would.

Validation

Honest hold-outs

Hold out whole drill holes, regions, deposits or later periods, never random rows next to the training data.

Validation

Strong baselines

Compare against the method an expert would actually use, such as kriging or inverse-distance weighting.

Reliability

Shortcut tests

Check whether a model learned the science or just where samples were taken, using position-only and matched baselines.

Scientific ML

Physics checks

Search for any load history on which a surrogate creates energy; no test found one.

Uncertainty

Uncertainty

Calibration, conformal prediction sets and geological realisations to say how sure a prediction is.

Practice

Clear reporting

Confidence intervals over independent units and ratings fixed before the results come in.
